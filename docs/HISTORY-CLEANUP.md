# 历史额度清理

入口：系统设置 → 历史额度清理 → 管理授权 → 读取保留策略。
保留天数为1至3650整数，默认90。首次升级自动清理默认关闭，保存期限不会立即删除。明确启用自动清理后在启动及每6小时运行一批，每批最多200份报告。

“仅预览，不删除”使用当前输入天数，展示固定截止点、可清理总数、受保护报告数、本批报告/窗口行数、涉及账号设备数量和时间范围。预览有效5分钟，仅驻留服务内存；重启或修改策略失效。预览不备份历史、不改快照或配置。

执行需要管理员授权、有效一次性预览及输入“删除历史额度”二次确认。删除在短事务中重新检查策略和本批候选，改变则拒绝并要求重新预览；最多200份完整报告，不自动连续删除，不自动重试不确定请求。每份报告所有窗口一起删除，失败整批回滚。

保护集合始终包括：每台设备最后引用报告、按采集时间排序的每设备/每账号最新报告，以及排除异常未来时间后各自最新有效报告。隐藏账号同样受保护。仅当报告全部窗口的服务端上报时间都早于截止点，且整报告不在保护集合中，才能删除。

只修改 quota_snapshot 和独立 history_cleanup_policy；不清理账号映射、隐藏状态、设备记录、client_id、令牌、配对码、上报周期、地址迁移设置、客户端队列或凭据。不执行 VACUUM，文件空间不一定立即缩小。按要求不备份历史，真实删除不可撤销。

管理API全部使用现有 bootstrap 授权：POST /api/history-cleanup/policy 读取；/save 接收 retention_days、automatic_enabled、version；/preview 接收 retention_days；/execute 接收 preview_token、confirmation。policy返回最新版本；preview返回安全统计及一次性凭证；execute返回删除报告数、窗口行数及剩余报告数。凭证过期或数据变化返回409，不删除。

首次本机验收禁止删除真实历史：内存合成库验证删除、回滚及并发保护；正式库只验证读取策略、预览、拒绝无授权和无效凭证，自动保持关闭。不因部署启动触发真实删除。
