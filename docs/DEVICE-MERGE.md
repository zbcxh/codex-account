# 合并旧设备

入口：设备监控 → 打开离线旧记录详情 → 合并旧设备。先确认旧采集器已停用，选择同一电脑当前正常上报、希望保留的目标设备；不要仅根据名称判断。

读取预览后检查双方名称、主机名、完整client_id、编号及迁移报告/窗口数；输入“源编号->目标编号”确认方向。预览5分钟一次性有效，源仍在线、双方状态变化、重复使用或数据异常时拒绝。

成功后所有源额度窗口仅迁移machine_id到目标，不叠加账号额度，不拆报告、不删除报告。目标client_id、令牌、标签、当前报告、上报周期及地址设置均保持；源设备的周期和地址设置不覆盖目标。源当前报告引用清空，源身份标记退役，不能上报、获取迁移证明或再次配对。默认设备列表和迁移设置不再显示源记录；数据库保留源记录及合并方向作为审计，不把旧令牌发给目标或页面。

不将源旧账号冒充目标当前账号，目标无报告时继续显示未知，等待目标下次核验。跨账号历史分别保留。合并无一键撤销；本操作不迁移客户端本地配置，不更换目标采集器。

API：管理员POST /api/machine/:source/merge-preview 请求 {target_id}；POST /api/machine/:source/merge 请求 {target_id,merge_token,confirmation:"source->target"}。预览不返回令牌。执行事务重新检查双方及历史范围，失败全部回滚。

本次仅以本机内存合成库和静态类型/构建检查验证，不操作浏览器、不执行真实设备合并。页面及业务流程由用户验收。
