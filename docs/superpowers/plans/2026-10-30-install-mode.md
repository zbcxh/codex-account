# 安装入口模式选择

用户要求安装入口提供常驻和单轮选择，默认单轮。

## 行为与约束

- `Install.cmd` 进入同用户提权后的选择菜单：1为单轮默认，2为常驻。回车选择1，无效输入不执行安装。
- 同一源码和程序保留两模式；新设备沿用配对流程，选择常驻时不得先运行单轮采集。
- 已有设备改变模式需明确确认，取消不写业务文件；禁用和暂停保持，运行中生命周期锁拒绝覆盖。
- 常驻转单轮使用实际内部周期，不能以期望周期代替；保留client_id、令牌、服务地址和队列。
- 仅隔离测试，不操作真实设备、任务或数据，不部署或推送。

## 实施与验证

1. 实现入口选择、模式转换及必要安装器参数，先补失败的任务/交互替身测试，再验证新旧安装和禁用保护。
2. 独立检查模式默认、首次常驻不冷启动单轮、跨用户拒绝、取消与锁冲突、周期及身份字节保持。
3. 使用稳定源码构建并维护AOCI、同步CodeGraph，重新生成统一入口白名单包，记录源码和产物摘要。

执行方式：使用 subagent-driven-development 完成安装器实现任务，主代理核验与独立审查后收尾。当前工作区包含既有修改，不自动提交或覆盖。
