# 临时采集进程树保护

每轮仍使用临时 app-server，仅禁用该临时实例的 plugins；账号前后身份与额度归属校验保持不变。

- 使用匿名 Windows Job Object，将本轮 app-server 和绑定后创建的子进程归为一组。
- 作业统一设置 BelowNormal CPU 优先级，不再忽略优先级设置错误。
- 正常完成、查询超时或异常时终止本作业全部进程，并最多等待 5 秒确认活动进程归零。
- 采集器异常退出导致句柄关闭时，系统也会终止已绑定的进程树。
- 创建或绑定作业失败则停止本轮；绑定失败仍尝试回收已启动的主进程。不按名称查杀任何进程。

## 边界

本次不改变 Process.Start 启动方式，启动与绑定之间仍有短暂窗口。绑定前已经启动的子进程不保证纳入作业。尚未承诺消除最初的启动峰值。

BelowNormal 是 CPU 调度优先级，不是 CPU、内存或磁盘带宽硬上限。未设置内存硬限额，以免初始化失败；未引入常驻实例、目录扫描或登录凭据读取。

如果机器已有不兼容的作业限制，绑定会安全失败，不继续查询。实际桌面环境兼容性及卡顿改善需功能测试确认。

## 代码层面验证

运行 `powershell.exe -NoProfile -File .\tools\test-temporary-process-tree.ps1`：只创建合成父子进程，检查低优先级继承、正常回收、关闭句柄回收、主进程提前退出后的子进程回收、RPC 超时路径，以及独立进程未被误杀。输出写入独立临时目录。不执行真实采集，不操作计划任务。

编译候选可用 `client-compiled\build.ps1 -OutputDirectory <隔离目录>`，不得指定正式安装目录。候选验证通过也不代表已部署或实测性能改善。
