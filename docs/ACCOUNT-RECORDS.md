# 账号记录管理与额度卡片

账号额度按所有可见已知账号生成：历史快照账号与手动映射账号取并集，未知设备身份不计作账号。每个账号取最新有效完整报告，设备切号不会让旧账号卡片消失。当前在线使用设备与最近使用设备分别展示；离线额度标明历史读数，不能视为实时读数。

桌面采用3列，六个账号自然为两行；窄屏为2列/1列，不硬编码账号数。支持全部、在用、离线/待采集、预警筛选及搜索，展示每个窗口剩余/已用/重置、采集时间、负责人和设备标签。

隐藏由管理员主动恢复；普通上报及迟到补传不再解除隐藏。

账号映射页保留“删除映射”（仅名称/负责人/备注），另加“删除账号记录”（删除该账号全部额度历史、映射和隐藏标记）。永久删除需要管理员授权、读取5分钟一次性预览、重复输入完整账号ID；预览与事务执行均检查账号是否有在线使用设备，仍在用则拒绝。

删除保留所有设备、client_id 和令牌，不访问或修改客户端。引用被删除报告的设备将清空报告指针，保持账号未知，不能回退选择另一个旧账号。删除时间屏障忽略删除前采集的迟到队列，按已处理返回；删除后采集的新报告仍可重新创建该账号。

API：POST /api/account/:id/delete-preview 返回报告/窗口行数、设备数、有效期及delete_token；POST /api/account/:id/delete 请求 {delete_token,confirmation:完整账号ID}，返回删除数量。全部使用既有bootstrap管理员鉴权，不返回设备令牌。账号恢复在线、范围发生变化、凭证过期或重复使用时拒绝。发现混合账号报告时拒绝操作；数据库失败整笔回滚。

本轮只做源码、构建和内存合成数据检查，不操作浏览器、不部署、不删除真实记录。设备永久删除仍待用户确认，不包含在本轮功能中。
